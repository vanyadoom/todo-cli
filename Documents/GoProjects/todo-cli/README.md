# 📋 Todo CLI with Analytics

Консольное приложение для управления задачами с аналитикой.

## 🚀 
 Возможности
- ✅ Создание задач с тегами и приоритетами
- ✅ Просмотр всех задач
- ✅ Завершение и удаление задач
- ✅ Фильтрация по статусам
- ✅ Статистика и аналитика
- ✅ Сохранение в JSON файл

## 🛠 Установка
```bash
git clone https://github.com/ТВОЙ_НИК/todo-cli.git
cd todo-cli
go mod download
go run main.go
