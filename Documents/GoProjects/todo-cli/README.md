### 📜 Todo CLI

### 🚀 О проекте

**Todo CLI** — это легковесный, консольный менеджер задач, написанный на языке **Go**. Проект разработан с нуля и демонстрирует применение лучших практик промышленной разработки: модульную архитектуру, разделение зон ответственности, безопасную работу с файловой системой и идиоматичную обработку ошибок.

### ✨ Ключевые фичи

* **⚡ Умный поиск по короткому ID:** Благодаря интеграции пакета strings, пользователю не нужно вводить длинный 36-символьный UUID. Достаточно ввести первые **8 символов** (как в Git или Docker UX).
* **📦 Модульная архитектура:** Логика приложения строго разделена на независимые пакеты (task, storage, analytics), что полностью исключает проблему циклических зависимостей [INDEX].
* **💾 Локальная БД на JSON:** Автоматическое сохранение (MarshalIndent) и загрузка (Unmarshal) данных в файл tasks.json с красивыми отступами для удобного чтения человеком.
* **📊 Продвинутая аналитика:** Встроенный модуль аналитики в реальном времени считает прогресс выполнения задач, средний приоритет и группирует задачи по кастомным тегам.
* **🛡 Отзоустойчивость:** Программа валидирует ввод пользователя, безопасно обрабатывает пустые состояния и отсутствие файлов без падения в panic.

### 🛠️ Запуск и установка

Для запуска проекта вам понадобится установленный **Go версии 1.16+**. 

1. **Клонируйте репозиторий:** 

bash

git clone https://github.com/ТВОЙ_НИКНЕЙМ/todo-cli.git
cd todo-cli

2. **Синхронизируйте зависимости:** 

bash

go mod tidy


3. **Запустите интерактивное меню:** 

bash

go run main.go

### 🎛️ Инструкция по использованию

После запуска программы перед вами откроется интерактивное меню: 

1. **Показать все задачи** — Выводит список текущих задач с их статусами, названиями, тегами и первыми 8 символами ID (например, ⏳ [a1b2c3d4] Изучить указатели).
2. **Добавить задачу** — Пошаговый ввод: Название ➡️ Описание ➡️ Приоритет (1-5) ➡️ Теги (через запятую).
3. **Завершить задачу** — Переводит задачу в статус "Выполнено". Достаточно ввести короткие 8 символов ID.
4. **Удалить задачу** — Полностью стирает задачу из базы данных по её короткому ID.
5. **Показать статистику** — Выводит красивый отчет с процентом выполнения и распределением задач по тегам.
